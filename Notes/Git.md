# Git Cheat Sheet

## Workflow

git status
→ Voir les changements

git add .
→ Préparer les modifications

git commit -m "Message"
→ Créer une nouvelle version

git push
→ Envoyer les commits sur GitHub

git pull
→ Récupérer les modifications du dépôt distant

---

## Historique

git log --oneline

---

## Vérifier les dépôts distants

git remote -v

---

## Branches

git branch
git branch -M main

---

## SSH

ssh -T git@github.com

Vérifie que la connexion à GitHub fonctionne.
