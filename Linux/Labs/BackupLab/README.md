# BackupLab

## Objectif

Simuler une tâche d'administration Linux consistant à sauvegarder des fichiers de logs, créer une archive compressée et gérer les permissions.

## Arborescence

logs/
backup/
archive/

## Compétences travaillées

- mkdir -p
- Brace Expansion
- touch
- echo
- cp
- tar
- chmod

## Notions apprises

- Création d'une archive (.tar.gz)
- Compression avec gzip
- Extraction d'une archive
- Différence entre chemin absolu et relatif
- Utilisation de -C avec tar
