# Linux

Ce dossier regroupe les laboratoires, scripts et notes Linux réalisés dans le cadre de ma préparation au Master 1 Cybersécurité (IRIS).

---

## Objectifs

- Renforcer mes compétences en administration Linux.
- Développer de bonnes pratiques en ligne de commande.
- Construire un portfolio technique documenté.

---

## Laboratoires

### CyberLab

Compétences travaillées :

- Navigation dans le système de fichiers.
- Manipulation de fichiers et dossiers.
- Permissions (`chmod`).
- Compréhension des droits Linux (`755`, `644`, `600`).

### BackupLab

Compétences travaillées :

- Création d'une arborescence avec `mkdir -p`.
- Utilisation de la Brace Expansion (`{}`).
- Sauvegarde de fichiers avec `cp`.
- Création d'archives avec `tar`.
- Compression avec `gzip` (`.tar.gz`).
- Extraction d'archives (`tar -xf`).
- Extraction dans un dossier spécifique (`-C`).
- Différence entre chemins absolus, relatifs et `~`.
