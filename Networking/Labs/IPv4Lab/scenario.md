# Scénario 1
Un nouveau stagiaire rejoint l'équipe.
Il connaît Internet, mais il ne comprend pas comment les adresses IPv4 fonctionnent.
Ton responsable te demande de rédiger une documentation simple afin qu'il puisse comprendre les notions de base avant de passer au subnetting.

# Scenario 2 

## Contexte

Vous rejoignez une équipe réseau en tant que technicien junior.

Votre responsable vous fournit plusieurs adresses IPv4 avec leurs préfixes CIDR.

Votre mission est d'identifier les informations principales de chaque sous-réseau.

## Objectifs

Pour chaque adresse IPv4, déterminer :

- le masque de sous-réseau ;
- le nombre de bits réseau ;
- le nombre de bits hôte ;
- la taille du bloc ;
- l'adresse réseau ;
- le premier hôte utilisable ;
- le dernier hôte utilisable ;
- l'adresse de broadcast ;
- le nombre d'hôtes utilisables.

## Préfixes étudiés

- /8
- /16
- /24
- /25
- /26
- /27
- /28

## Exemple

Adresse donnée :

`10.20.30.197/27`

Le technicien doit déterminer toutes les informations du sous-réseau sans utiliser de calculateur de subnetting.
