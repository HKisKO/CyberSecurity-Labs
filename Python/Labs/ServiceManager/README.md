ice Manager

Programme Python en ligne de commande permettant de gérer des services réseau et leurs ports.

## Fonctionnalités

- Afficher les services disponibles
- Rechercher un service par numéro de port
- Rechercher un port par nom de service
- Ajouter un service
- Supprimer un service
- Gérer les erreurs de saisie utilisateur
- Menu interactif

## Concepts Python utilisés

- Dictionnaires
- Fonctions
- Boucles `while` et `for`
- Conditions `if / elif / else`
- `input()`
- `try / except`
- `return`
- `break`
- `.items()`, `.values()` et `.pop()`

## Exemple

Services disponibles au lancement :

- 22 : SSH
- 80 : HTTP
- 443 : HTTPS

Le programme permet ensuite de rechercher, ajouter ou supprimer des services depuis un menu interactif.
