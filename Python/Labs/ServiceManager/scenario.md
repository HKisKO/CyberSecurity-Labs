
Chaque service est associé à un numéro de port.

## Mission

Créer un programme Python proposant un menu interactif permettant de :

1. Afficher tous les services.
2. Rechercher un service par port.
3. Rechercher un port par service.
4. Ajouter un nouveau service.
5. Supprimer un service.
6. Quitter le programme.

## Contraintes

Le programme doit :

- utiliser un dictionnaire pour stocker les ports et services ;
- être organisé avec plusieurs fonctions ;
- rester actif grâce à une boucle `while` ;
- gérer les choix invalides ;
- gérer les erreurs lorsqu'un entier est attendu ;
- empêcher l'ajout d'un port déjà existant ;
- empêcher l'ajout d'un service déjà présent.

## Objectif

Construire un premier programme Python complet et interactif en réutilisant les notions fondamentales de Python.
